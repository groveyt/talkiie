# Security and privacy reports

Talkiie's promise is about what leaves your Mac, so a privacy problem is treated as a security problem.
Please report privately anything that could:

- send audio, text or anything else to a destination not listed in the README ("What the app connects to");
- read screen or field contents when the corresponding setting is off;
- keep audio on disk;
- let a web page or another app trigger recording, text insertion or a model download;
- let a modified update or model be installed (Sparkle signature, model checksum).

## How to report

Use GitHub's private vulnerability reporting for this repository ("Security" tab → "Report a vulnerability").
If that is not available, use the form at <https://talkiie.yyt.app/feedback> and write "security" in the first
line; you will be contacted privately. Please do not open a public issue for these.

Include the Talkiie version (Settings → About), the macOS version, and the steps or code location.

## What to expect

This is a one-person project. You will get an answer, usually within a week. Fixes ship as a normal update
through the app's update channel; the release notes say what was fixed once the update is out.

## Supported versions

Only the latest release receives fixes.
